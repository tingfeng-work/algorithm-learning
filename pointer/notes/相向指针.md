# 相向指针

## 两数之和

基础题目：167. 两数之和 II 、15. 三数之和

扩展题目：2824.统计和小于目标的下标对数目、16.最接近的三数之和、18.四数之和、611.有效三角形的个数

### 概述

两数之和为 target 的题目中，为了利用有序数组的性质：通过相向双指针指向最大与最小，和小于 target，则最小指针移动，相反则最大指针移动，实现了 O(n) 的时间复杂度，本质上是利用单调性一次获取了 O(n) 的信息。这道题可以推广到三数之和与四数之和；在推广时，要注意题目中的不重复结果的处理，以及利用单调性优化循环遍历，结合代码：

```java
   for (left++; left < right && nums[left] == nums[left - 1]; left++) ;// 跳过重复
   
   // 优化
   if (nums[i] + nums[i + 1] + nums[i + 2] > 0) break;
   if (nums[i] + nums[len - 2] + nums[len - 1] < 0) continue;
   if (i > 0 && nums[i] == nums[i - 1]) continue;
```

### 拓展

在完成四数之和时，遇到了整形溢出的问题。

在 Java 中**表达式的类型由“参与运算的操作数”决定**。这说明：

```
long s = a + b // a,b 为 int 结果还是有可能溢出
long s = (long) a + b // long + int 会自动转换为 long 类型计算不会溢出
```

防止溢出的常见写法：

```java
long sum = (long)a + b + c;

long sum = 0L + a + b + c;
```

## 接雨水

基础题目：11.盛最多水的容器、42.接雨水

拓展题目：125.验证回文串、2105.给植物浇水

### 概述

今天巩固了相向指针的一些具体的应用题，有天然的相向指针的题目：验证回文串、给植物浇水；从他们的题意中就可以明确感知到这道题需要用到相向指针，需要注意的是指针移动的时机，在给植物浇水中，灌满水后需要立刻浇水，说明一次循环时必须同时更新左右指针，这道题还有隐含条件就是水桶的最大容量总是大于植物需要的水量的，需要从题目提示中获取这个信息；而在验证回文串中，左右指针的移动同样考究，每次循环中，要么只移动一个指针（当指针所指的字符不是合法字符时），要么两个一起移动；而在盛水最多的容器以及接雨水题目中，关键点在于容器盛水以及木桶盛水的取决于短的一边，而一个容器有左右两边，与相向指针联系上了，这两道题每次循环只会移动一次指针，同时更新答案。

### 拓展

在判断回文串时，学到了一个库函数的使用：

```
Character.isLetterOrDigit(char c) //判断一个字符是否是字母或者数字
```



## 总结

这次关于相向指针的复习，收获在于对相向指针的指针更新时机有了更好的理解，在一次循环中有可能一次更新一个指针，也有可能一次更新两个，本质上相向指针的题目都遵循一个“单调性”，不论是求数的和为 target 还是应用中容器盛水，求和为 target 的单调性好理解，数组有序；而容器盛水中的单调性在于对于容器短的一边不变，另一边往内收时，单调减少；而接雨水、验证回文串、给植物浇水则属于利用相向指针让样本空间单调减少。
