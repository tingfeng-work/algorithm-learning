# 滑动窗口（同向双指针）

## 最短 最长 方案数

基础题目：209.长度最小的子数组、3.无重复字符的最长子串、713.乘积小于 K 的子数组

扩展题目：3090.每个字符最多出现两次的最长子字符串、2958.最多 K 个重复元素的最长子数组、2730.找到最长的半重复子字符串、1004.最大连续 1 的个数Ⅲ、2962.统计最大元素出现至少 K 次的子数组、2302.统计得分小于 K 的子数组数目、1658.讲 x 减到 0 的最小操作数、3795. 不同元素和至少为 K 的最短子数组长度、76.最小覆盖子串

### 概述

在 209.长度最小的子数组题中，由于数组都是正数，则子数组的和随着元素个数的增加而增加，为了利用这个单调性，即越长越合法引入了同向的双指针，它的本质与相向双指针相同，都是利用数组或字符串的性质来缩小搜索的样本空间。该方法通常涉及子数组、子串，这是因为滑动窗口，可以很好根据子串、子数组连续不间断的特点来枚举所有可能构成答案的组合。同时窗口内的元素通常满足一定条件，根据不同的条件，我将其分为越长越合法、越短越合法、以及特定条件三种题型。其中头两种题型中，子数组满足的条件往往存在单调性，例如 209 中子数组和随着元素个数增加而增加，越满足题目大于等于 target 的要求；713 乘积小于 K 的子数组中子数组的乘积随着元素个数增加而增加，越不满足要求，反之，数组越短、越满足要求；以及 3 中无重复字符的特定条件。

这些题目都有一个共同点，那就是每次窗口右端点向右扩展时，会影响窗口内的元素是否满足题目要求，同时左端点移动时，也会影响；而这两个端点的移动对应相反的状态，例如 209 中右端点的移动使窗口内元素和变大，越合法，而左端点的移动则是使窗口内元素和变小，越不合法，而答案往往就存在于状态转化之间。结合代码：

```java
int left = 0;
for (int right = 0; right < len; right++) {
            当前操作的元素加入窗口更新状态
            while (条件) {
               	右移窗口左端点
                更新状态
            }
}// 答案的更新可以在内层循环内，也可以在内层循环前或后
```
