## 2. Group 卷积实现

### 2.1 核心认识

卷积核在输入上滑动，每到一个位置，将覆盖区域与卷积核对应元素相乘并求和，得到输出特征图中的一个元素。这里不是矩阵乘法，也不是用结果替换原矩阵，而是在生成新的特征图。

卷积减少参数的主要原因是：

- **局部连接**：每次只观察输入的一块局部区域；
- **参数共享**：同一个卷积核在所有空间位置重复使用。

输入张量采用 NCHW：

```text
[N, Cin, H, W]
```

卷积核张量为：

```text
[Cout, Ck, Kh, Kw]
```

其中：

- `N`：一次处理的样本数；
- `Cin`：输入通道数；
- `Cout`：输出通道数，也就是卷积核数量；
- `Ck`：每个卷积核实际连接的输入通道数；
- 一个卷积核生成一个输出通道。

普通卷积：

```text
Ck = Cin
```

Group 卷积：

```text
Ck = Cin / groups
```

同时必须满足：

```text
Cin % groups == 0
Cout % groups == 0
```

### 2.2 循环是如何推导出来的

输出张量形状为：

```text
[N, Cout, Hout, Wout]
```

因此先枚举要计算的输出元素：

```text
batch → group → 组内输出通道 → 输出高度 → 输出宽度
```

一个输出元素需要对以下三个维度求和：

```text
组内输入通道 → 卷积核高度 → 卷积核宽度
```

完整循环顺序为：

```text
batch
→ group
→ localOutChannel
→ outRow
→ outCol
→ localInputChannel
→ kernelRow
→ kernelCol
```

前五层决定“计算输出张量中的哪个元素”，后三层决定“该元素由哪些乘积累加得到”。

### 2.3 我一开始没有独立写出的原因

真正卡住的不是卷积概念，而是三个问题同时出现：

1. 从输出张量形状推导外层循环；
2. 从卷积公式推导求和循环；
3. 将组内局部通道编号映射为完整张量中的全局编号。

核心映射：

```java
int inputChannelsPerGroup = inChannels / groups;
int outputChannelsPerGroup = outChannels / groups;

int realInputChannel =
        group * inputChannelsPerGroup + localInputChannel;

int realOutputChannel =
        group * outputChannelsPerGroup + localOutputChannel;
```

这与之前 MoE 题中“组号、组内编号、全局专家编号”的困难相同。本质都是局部编号到全局编号的转换。

### 2.4 可复用经验

遇到多维数组模拟题时：

1. 先写输出张量形状；
2. 输出下标对应外层循环；
3. 求和公式中的下标对应内层循环；
4. 单独写出局部编号到全局编号的映射；
5. 最后再处理一维展开下标。

## 3. 基于逻辑回归的意图分类器

### 3.1 完整数据流

```text
特征字符串
→ 长度为7的One-hot
→ z = w·x + b
→ p = sigmoid(z)
→ error = p - y
→ SGD更新w和b
→ 阈值分类
```

`ABCDEFG` 按固定位置编码，字母存在记为 1，不存在记为 0。重复字母仍只记为 1：

```java
result[c - 'A'] = 1;
```

例如 `BBA`：

```text
[1, 1, 0, 0, 0, 0, 0]
```

### 3.2 为什么这是 SGD

SGD 是随机梯度下降。本题 `batch size = 1`，每处理一个训练样本，就立即计算梯度并更新一次参数：

```text
一个样本 → 一次预测 → 一次梯度 → 一次更新
```

这不同于使用全部样本求平均后再更新的批量梯度下降。

### 3.3 更新公式的推导

前向计算：

\[
z=w\cdot x+b,\qquad p=\sigma(z)
\]

二分类交叉熵：

\[
L=-[y\ln p+(1-y)\ln(1-p)]
\]

Sigmoid 与二分类交叉熵组合后有关键结论：

\[
\frac{\partial L}{\partial z}=p-y
\]

又因为：

\[
\frac{\partial z}{\partial w_j}=x_j,
\qquad
\frac{\partial z}{\partial b}=1
\]

所以：

\[
\frac{\partial L}{\partial w_j}=(p-y)x_j
\]

\[
\frac{\partial L}{\partial b}=p-y
\]

根据梯度下降的通用公式：

\[
参数\leftarrow参数-学习率\times梯度
\]

得到：

\[
w_j\leftarrow w_j-0.1(p-y)x_j
\]

\[
b\leftarrow b-0.1(p-y)
\]

### 3.4 本题暴露的知识缺口

我的主体代码可以独立实现，但原题没有给梯度公式时，我不知道如何从交叉熵和 Sigmoid 推导参数更新。

需要直接记住并能够解释：

```text
Sigmoid + BCE：误差项为 p - y
dw = (p - y) * x
db = p - y
```

以后遇到训练类编程题，先写出计算图：

```text
w、b → z → p → L
```

再沿着计算图反向使用链式法则。

## 4. 商品购买预测

### 4.1 相较上一题新增的内容

| 对比项 | 意图分类器 | 商品购买预测 |
|---|---|---|
| 特征 | One-hot | 连续数值特征 |
| 更新方式 | 单样本立即更新 | 全样本累加后统一更新 |
| 训练停止 | 固定20轮 | 最大轮数或损失收敛 |
| 正则化 | 无 | L2 正则化 |
| 输出 | 标签 | 标签和概率 |

### 4.2 一轮训练的标准流程

```text
1. 使用当前参数计算全部样本的概率
2. 计算平均交叉熵损失
3. 单独计算L2正则损失
4. 得到总损失并判断是否提前停止
5. 累加全部样本的梯度
6. 求平均并加入L2梯度
7. 统一更新一次w和b
```

总损失：

\[
L=
-\frac1n\sum_i[y_i\ln p_i+(1-y_i)\ln(1-p_i)]
+\frac{\lambda}{2n}\sum_jw_j^2
\]

权重梯度：

\[
dw_j=
\frac1n\sum_i(p_i-y_i)x_{ij}
+\frac{\lambda}{n}w_j
\]

偏置梯度：

\[
db=\frac1n\sum_i(p_i-y_i)
\]

通常只正则化权重，不正则化偏置。

### 4.3 首次实现中的错误

#### 错误一：交叉熵误用 `Math.exp`

错误代码：

```java
Math.exp(p + EPSILON)
```

正确代码：

```java
Math.log(p + EPSILON)
```

原因是交叉熵使用自然对数：

```text
Math.log(x) = ln(x)
Math.exp(x) = e^x
```

#### 错误二：在样本循环内部求平均并更新参数

首次实现将以下操作放进了样本循环：

```text
求平均 → 加入L2梯度 → 更新参数
```

这样每处理一个样本都会修改参数，不再是批量梯度下降；而且已累积梯度会反复除以 `n`，数值含义也被破坏。

正确的大括号结构是：

```java
for (int i = 0; i < n; i++) {
    // 这里只累加全部样本的梯度
}

// 样本循环结束后求平均
// 加入L2梯度
// 统一更新一次参数
```

#### 隐患三：特征类型使用 `int`

题目描述为数值特征，隐藏测试可能含小数。更稳妥的写法是：

```java
double[][] trainFeatures;
double[][] testFeatures;
```

并使用 `nextDouble()` 读取。

### 4.4 可复用经验

训练代码中，大括号位置本身就是算法含义：

- 更新在样本循环内：SGD；
- 更新在小批次循环外：Mini-batch；
- 更新在全部样本循环外：Batch Gradient Descent。

因此不能只检查公式，还要检查“梯度在哪一层清零、累加和更新”。

## 5. 基于决策树预判资源调配优先级

### 5.1 核心思路

决策树可以理解为一组由树组织起来的 `if-else`：

```text
从根节点开始
→ 读取当前节点指定的特征下标和阈值
→ 特征值 <= 阈值则进入左子节点
→ 否则进入右子节点
→ 到达叶子后输出分类标签
```

### 5.2 首次实现中的核心问题

一开始容易按照样本的特征数量循环：

```java
for (int j = 0; j < f; j++)
```

但决策树的路径长度与特征数量没有直接关系，同一个特征也可能在不同节点被重复使用。正确做法是遍历节点路径：

```java
int node = 0;

while (!isLeaf(node)) {
    int featureIndex = ...;
    node = sample[featureIndex] <= threshold
            ? leftChild
            : rightChild;
}
```

关键认识是：

> 不是按顺序遍历样本特征，而是由当前决策节点决定本次查看哪个特征。

### 5.3 可复用经验

题目给出的树如果已经用数组保存，数组下标就是节点编号，不一定需要真正构建指针式二叉树。只要维护当前节点下标即可完成推理。

此题独立完成并通过测试，说明树结构推理流程已经掌握。

## 6. F1 值最优的决策树剪枝

### 6.1 为什么不能贪心地判断每个节点是否剪枝

剪枝后，某个内部节点可以直接变为叶子，也可以保留左右子树。最终目标是全局 F1：

\[
F1=\frac{2TP}{2TP+FP+FN}
\]

F1 不是左右子树 F1 的和，也不能通过每个子树单独选择最大 F1 得到全局最优解。因此不能把状态定义成“子树的最大 F1”。

### 6.2 样本统计

让每条验证样本沿原始决策树向下推理，并在它经过的每个节点统计：

```text
positiveCount[u]：经过节点u的正样本数
negativeCount[u]：经过节点u的负样本数
```

如果节点 `u` 被剪成叶子：

- 标签为 1：这些正样本贡献 TP，负样本贡献 FP；
- 标签为 0：TP 和 FP 都不增加。

### 6.3 树形 DP 状态

定义：

```text
dp[u][tp] = 节点u的子树产生tp个TP时，可以达到的最小FP
```

为什么只保留最小 FP？

对于相同 TP，FP 越小，最终 F1 一定越大，所以较大的 FP 状态永远不会成为更优答案，可以被支配并删除。

每个节点有两类方案：

1. **剪枝**：当前节点直接成为叶子；
2. **不剪枝**：保留左右子树并合并其 DP。

左右子树使用树上背包合并：

```text
totalTP = leftTP + rightTP
totalFP = leftFP + rightFP
```

对相同 `totalTP` 取最小 `totalFP`。

### 6.4 根节点计算答案

设验证集正样本总数为 `P`，则：

\[
FN=P-TP
\]

代入 F1：

\[
F1=\frac{2TP}{P+TP+FP}
\]

在根节点所有可达的 `TP` 状态中枚举并取最大值。

### 6.5 本题真正学到的方法

当目标函数不能在子问题间直接相加时：

1. 不要强行把目标值作为 DP 状态；
2. 找出能在子问题间相加的充分统计量；
3. 枚举其中一个维度，对另一个维度保存最优值；
4. 最后再使用原目标函数统一计算答案。

本题中可加的量是 `TP` 和 `FP`，而不是 F1 本身。

## 7. 五道题共同的方法论

### 7.1 先识别题目处于哪个计算层次

| 题型 | 首先回答的问题 |
|---|---|
| 张量模拟 | 输出的每个维度是什么？每个输出元素对哪些维度求和？ |
| 模型训练 | 前向计算、损失、梯度、更新分别是什么？ |
| 树结构推理 | 当前状态是节点还是特征？终止条件是什么？ |
| 非线性指标优化 | 哪些统计量可以在子问题之间相加？ |

### 7.2 公式翻译为代码的统一步骤

1. 标出等号左侧的自由下标——它们通常对应外层循环；
2. 标出求和符号中的下标——它们通常对应内层累加；
3. 标出局部编号与全局编号之间的映射；
4. 明确非法状态、初始状态和终止条件；
5. 检查更新发生在哪一层循环。

### 7.3 AI 背景题不只是传统算法包装

今天的五道题可以分成两类：

因此备考不能只背传统算法模板，还要能够把常见 AI 公式翻译为数组、循环和状态。
